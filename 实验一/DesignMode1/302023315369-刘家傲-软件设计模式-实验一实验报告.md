# 1.实验目的
#### 通过完成鸭塘游戏程序，理解并掌握策略模式。

# 2.实验原理
#### 使用策略模式管理不同种类鸭子的行为。

# 3.实验过程
## 3.1 鸭塘描述
#### 鸭塘有四种不同的鸭子：野鸭、红鸭、橡皮鸭、诱饵鸭。

## 3.2 鸭子行为
#### 野鸭会飞，叫声为“咕咕嘎嘎”。
#### 红鸭会飞，叫声为“哇哇哇”。
#### 橡皮鸭不会飞，叫声为“吱吱”。
#### 诱饵鸭不会飞，也不会叫。

## 3.3 实现过程
### 3.3.1 一个父类“鸭”
```java
package com.duck;

import com.behavior.FlyBehavior;
import com.behavior.QuackBehavior;

public abstract class Duck {
    FlyBehavior flyBehavior;
    QuackBehavior quackBehavior;
    public Duck(){

    }
    public abstract void display();
    public void performFly() {
        flyBehavior.fly();
    }
    public void performQuack() {
        quackBehavior.quack();

    }
    public void swim() {
        System.out.println("All ducks float,even decoys!");
    }
}
```

### 3.3.2 两个行为接口
#### 飞行行为接口：
```java
package com.behavior;

public interface FlyBehavior
{
    public void fly();
}
```
#### 喊叫行为接口：
```java
package com.behavior;

public interface QuackBehavior
{
    public void quack();
}
```
### 3.3.3 六个具体动作类
#### 不会飞动作类：
```java
package com.motion;

import com.behavior.FlyBehavior;

public class FlyNoWay implements FlyBehavior
{
    public void fly() {
        System.out.println("不好意思，俺不会飞.");
    }
}
```
#### 用翅膀飞动作类：
```java
package com.motion;

import com.behavior.FlyBehavior;

public class FlyWithWings implements FlyBehavior
{
    public void fly() {
        System.out.println("我飞，我飞，我飞飞飞！哈哈！");
    }
}
```
#### 咕咕嘎嘎叫动作类：
```java
package com.motion;
//咕咕嘎嘎的叫
import com.behavior.QuackBehavior;

public class QuackGugugaga implements QuackBehavior{
    public void quack(){
        System.out.println("咕咕嘎嘎，咕咕嘎嘎，咕咕嘎嘎！！");
    }
}
```
#### 哇哇叫动作类：
```java
package com.motion;
//哇哇哇的叫。
import com.behavior.QuackBehavior;

public class QuackWawawa implements QuackBehavior{
    public void quack(){
        System.out.println("哇哇哇！！哇哇哇！！");
    }
}
```
#### 吱吱叫动作类：
```java
package com.motion;
//吱吱的叫。
import com.behavior.QuackBehavior;

public class QuackZizi implements QuackBehavior{
    public void quack(){
        System.out.println("吱吱！！吱吱！！");
    }
}
```
#### 不会叫动作类：
```java
package com.motion;
//不会叫
import com.behavior.QuackBehavior;

public class QuackNoSound implements QuackBehavior{
    public void quack(){
        System.out.println("(心里默默想：我不会叫！)");
    }
}
```

### 3.3.4 四种鸭子的实现
#### 野鸭：
```java
package com.duck;
//野鸭
import com.duck.Duck;
import com.motion.FlyWithWings;
import com.motion.QuackGugugaga;

public class MallardDuck extends Duck {
    public MallardDuck() {
        quackBehavior = new QuackGugugaga();
        flyBehavior = new FlyWithWings();
    }
    public void display() {
        System.out.println("野鸭上场了！");
    }
}
```
#### 红鸭：
```java
package com.duck;

import com.duck.Duck;
import com.motion.FlyWithWings;
import com.motion.QuackWawawa;


public class RedDuck extends Duck {
    public RedDuck() {
        quackBehavior = new QuackWawawa();
        flyBehavior = new FlyWithWings();
    }
    public void display() {
        System.out.println("红鸭上场了！");
    }
}
```
#### 橡皮鸭：
```java
package com.duck;

import com.duck.Duck;
import com.motion.FlyNoWay;

public class RubberDuck extends Duck {
    public RubberDuck() {

    }

    }
}
```
#### 诱饵鸭：

### 3.3.5 让鸭子们出场

## 3.5 结果分析
#### 六个行为排列组合成了四种不同的鸭子。其中有的行为（飞行类的）是被多种鸭子共享使用的，有的（喊叫类的）则是某种鸭子单独占有的。
#### 每只鸭子实际上都实现了“飞”与“叫”这两项功能，只是实际情况下的行为是另外各自写好，实现在接口之外的。
#### 这样一来，即使出现一种新的叫声为“呱呱呱”的鸭子，只需要在动作实现类中添加一个“呱呱呱”的叫声，然后将这个动作赋予这只新鸭子，就实现了新功能，不需要修改以前的接口与父类。
# 4.实验总结

#### 通过使用策略模式完成鸭塘游戏程序的编写，我体会到了策略模式的巧妙，使用策略模式的软件在添加新功能时，不必修改之前已经写好了的类与接口，只需要将目光放在新功能的添加即可，这不仅在总体上减少了编码复杂度，也增强了软件的安全性，健壮性。
#### 同时策略模式把多种业务算法独立拆分，互不干扰，方便单独维护、测试。运行时可动态切换不同策略，满足多变业务规则。通过编写鸭塘游戏程序，我深刻的体会到了策略模式带来的方便，并令我有意识的将策略模式应用到将来的学习与工作中。
